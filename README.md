# STL Cut Studio AI

Aplicación de escritorio prevista para Windows 10/11 x64 orientada a importar, visualizar y, en fases posteriores, cortar y editar mallas 3D.

**Estado al 2026-11-05:** especificación y planificación documental. No hay código, scripts de instalación, compilaciones ni pruebas funcionales ejecutadas.

La fase 0.1 cubre ventana Qt, STL ASCII/binario, visor, pruebas y pipeline de compilación. Implementarla requiere aprobación previa del usuario. Los comandos de desarrollo se documentarán cuando existan y se verifiquen; actualmente no hay instrucciones ejecutables de instalación.

No se requieren API keys para el alcance local descrito de la fase 0.1. No hay servicios externos ni motores IA configurados.
